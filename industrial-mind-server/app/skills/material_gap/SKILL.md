# 物料缺口（Material）

统计产线物料缺口，支撑排产齐套性判断。

## 缺口口径
缺口 = 在库总量 - 订单扣减（审批中工令用量） - 草稿工令用量
- 差值 > 0 → 缺口 = 0（充足）
- 差值 < 0 → 缺口 = 差值的绝对值（需补货）

## 运用方法
1. 调用 `analyze_material_gap(factory)`（支持指定工厂）。
2. 按缺口量从大到小总结经验：物料、缺口数量、补货建议。
3. 直接给结论：存在缺口的物料与建议，或说明库存充足。

## 工具
- `analyze_material_gap(factory=None)`：物料缺口分析。
