# 堆存风险（Storage）

评估各产线堆存是否爆仓，支撑库容预警。

## 口径
- 堆存 = 该产线所有「已确认」工令数量合计
- 预堆存 = 该产线「待审批 + 草稿」工令数量合计
- 剩余空间 = 总容纳 − 堆存 − 预堆存
- 剩余空间 < 0 → 风险（爆仓）；≥ 0 → 正常

## 运用方法
1. 调用 `analyze_storage()`。
2. 指出存在爆仓风险的产线及其剩余空间，点出最紧张的产线并给出建议。
3. 直接给结论。

## 工具
- `analyze_storage()`：按产线堆存风险分析。
