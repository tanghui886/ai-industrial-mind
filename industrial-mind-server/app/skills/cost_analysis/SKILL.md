# 成本动因（Cost）

拆解单箱成本构成并定位成本驱动因素与异常项。

## 运用方法
1. 调用 `analyze_cost(month)`（缺省当月）。
2. 总结成本构成、主要成本动因与异常项。
3. 指出成本优化方向，直接给结论。

## 工具
- `analyze_cost(month="")`：按月返回单箱成本拆解、占比、动因与异常项。
