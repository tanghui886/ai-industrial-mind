# 集装箱制造业工业Agent深度适配方案（v6）

> **版本变更说明（v5 → v6）**：
> 1. 技术框架精简：前端Vue3，后端Python，大模型API切换为deepseek-v4-flash-0731，数据库统一为MySQL，移除图数据库Neo4j、消息队列Kafka、向量数据库Milvus、时序数据库TDengine、ES；
> 2. 新增移动端Web适配：支持手机浏览器访问，业务人员现场接单时通过自然语言输入即可触发智能排产Agent，实时输出排产可行性分析。

---

## 项目定位

**项目名称：** ContainerMind — 集装箱智造协同 Agent

**一句话定位：** 面向集装箱制造企业（特箱线），以"6+1"多 Agent 协同架构打通「焊接设备异常感知 → 质量缺陷诊断 → 维修工单调度 → 物料供应链预警 → 排产计划（线上化人工+智能） → 成本动因分析」全链路，实现产线异常 20 分钟闭环响应，AI 辅助决策 + 人工确认执行。

**v6新增定位：** 移动端即开即用，业务人员在客户现场通过手机Web端一句话录入意向订单，AI秒级返回排产可行性分析。

## 一、集装箱制造业行业痛点（"慢、散、盲、断、粗"适配版）

| 痛点 | 集装箱制造现状 | 量化损失 |
|------|---------------|---------|
| 慢 | 焊接机器人故障后人工排查耗时，涂装线停线等待维修 | MTTR 平均 3-6 小时，单线停线损失 ¥8-15万/天 |
| 散 | 焊接参数、质检报告、ERP库存、MES工单分散在不同系统 | 人工关联效率低，质量追溯需 2-4 小时 |
| 盲 | 焊接设备健康状态不透明，刀具/焊丝消耗无预测 | 非计划停机占年产值 2%-4% |
| 断 | 钢板/油漆/角件供应与生产排程脱节 | 缺料停线年均 15-20 次，紧急采购溢价 15%+ |
| **粗** | **排产依赖线下Excel手工操作，产能冲突靠人脑记忆；成本核算滞后，无法精准归集到工令/工段** | **排产调整响应慢（半天~1天），单车成本偏差>5%** |
| **新** | **业务人员现场接单依赖电话/微信沟通，无法实时查看产能空位，承诺交期靠经验** | **交期承诺准确率<70%，客户体验差** |

### 集装箱制造特殊性（特箱线）

| 维度 | 具体特征 |
|------|---------|
| 核心设备 | 焊接机器人（FANUC/ABB）、等离子切割机、折弯机、自动涂装线、总装夹具、门压试验台、气密检测设备 |
| 关键工艺 | 焊接（MAG/MIG）、涂装（底漆+面漆+木地板防腐）、总装（门端+侧壁+底架）、气密/水密试验 |
| 质量标准 | ISO 668（尺寸）、ISO 1496（试验）、CSC公约（安全）、IICL（检验标准） |
| 产品类型 | **特种箱为主**：储能箱、Ener系列（C+/D/E/S/X/H/W）、液冷方舱、滚装车架、气瓶箱、房屋箱、光伏平板、岸电箱等 |
| 供应链特征 | 钢板（耐候钢SPA-H）、油漆（防腐涂料）、木地板、角件/锁具、胶条、制冷剂（冷藏箱） |
| 生产模式 | **多品种小批量混线，订单驱动，交期敏感，箱型日产能差异大（15~150台/天）** |

## 三、六大 Agent 集装箱制造业适配设计

### 3.1 设备故障诊断 Agent

| 能力 | 集装箱场景适配 | 算法/模型 | 输入 | 输出 |
|------|--------------|----------|------|------|
| 焊接机器人故障诊断 | 送丝异常、焊枪堵塞、轨迹偏移、伺服报警 | FFT频谱 + RAG(维修手册) | 焊接电流/电压波形、报警代码 | 故障模式 + 根因 + 维修SOP |
| 涂装线异常检测 | 喷涂厚度不均、烘箱温度异常、链条卡滞 | STL分解 + 3σ规则 | 膜厚仪数据、温度曲线 | 异常点标记 + 调整建议 |
| 气密检测设备故障 | 压力传感器漂移、密封垫老化 | 趋势分析 + 基线对比 | 压力衰减曲线 | 设备校准建议 |
| RUL预测 | 焊枪电极寿命、涂装喷嘴磨损、刀具剩余寿命 | 时序预测（LSTM） | 历史消耗数据 + 工况参数 | 剩余寿命 + 更换建议 |
| 维修经济性分析 | 维修vs更换成本对比，关联排产影响 | 成本模型 + 排产联动 | 维修报价 + 停线损失 + 排产空位 | 经济性建议 + 最优维修窗口 |

### 3.2 质量异常分析 Agent

| 能力 | 集装箱场景适配 | 新增成本视角 |
|------|--------------|------------|

#### 3.5.1 线上化人工排产

（与v5一致，保留完整交互流程）

**交互流程（对齐Excel操作习惯）：**

```
Step 1: 选择排产月份
  ├─ 月份选择器（2026年1月~12月）
  ├─ 系统自动加载该月日历（含星期、节假日标识）
  └─ 显示每日计划生产工时（默认：工作日11h，周末0h，可编辑）

Step 2: 选择产线
  ├─ 下拉选择：QD-D（特箱线）/ SH-A / NT-A / NT-B / LYG-A
  └─ 加载该产线已有排产数据

Step 3: 添加排产工令（逐行录入，对齐Excel行结构）
  ├─ 工令号（必填）
  ├─ 订单确认表号（选填）
  ├─ 合同号（选填）
  ├─ 客户（必填）
  ├─ 箱型（必填，下拉选择）
  ├─ 数量（必填，正整数）
  ├─ TEU / CTEU（自动计算）
  ├─ 序列号（选填）
  ├─ 生产期限（必填）
  ├─ 预计交付状态（选填）
  ├─ 接单属性（必填：自接单/总部）
  ├─ 内外贸属性（必填：内贸/外贸）
  ├─ 交付地点（选填）
  ├─ 备注（选填）
  ├─ 日产能（必填：根据箱型自动带出，可手动调整）
  ├─ 日计划排产量（必填：≤日产能）
  └─ 订单类型标记

Step 4: 排产日期分配（核心操作）
  ├─ 方式A：指定开始日期 + 结束日期，系统自动均匀分配
  ├─ 方式B：在日历网格中逐日填写排产数量
  ├─ 方式C：拖拽排产条到目标日期（甘特图模式）
  └─ 系统实时校验：
      ├─ 单日排产量 ≤ 该箱型日产能
      ├─ 单日所有工令排产总量 ≤ 产线日总产能
      ├─ 日期必须为工作日
      ├─ 跨月订单自动拆分
      └─ 冲突高亮提示

Step 5: 校验与保存
  ├─ 系统自动汇总：已排产量、计划产能、剩余空位
  ├─ 冲突检测
  ├─ 支持保存为：草稿 / 正式排产
  ├─ 正式排产需审批（L2级）
  └─ 排产版本管理
```

### 3.6 成本动因分析 Agent

#### 3.6.1 直接材料成本管控

- 物料单价：移动加权平均法

## 五、人机交互设计（AI辅助 + 人工确认）

### 5.1 核心交互原则

- **AI 负责：** 信息聚合、模式识别、方案生成、风险提示、排产优化、意图识别
- **人工负责：** 最终决策、现场操作、安全确认、异常兜底、排产确认

### 5.2 L1-L4 人机协同分级

| 级别 | 场景 | Agent 权限 | 人工介入 | 前端交互 |
|------|------|-----------|---------|---------|
| L4 全自动 | 传感器数据采集、异常检测、日报生成 | 自主执行 | 仅接收通知 | 大屏自动刷新 |
| L3 条件自动化 | 故障诊断、工单派单、库存预警 | 自主执行，可人工覆盖 | 可调整/驳回 | 对话台 + 一键确认 |
| L2 辅助决策 | 停线维修、紧急采购、排产变更、成本分摊规则调整 | 生成方案，必须审批 | 审批通过方可执行 | 审批工作台 + 双签 |
| L1 信息提供 | 供应商替换、产线改造、年度预算 | 仅提供分析报告 | 人工全权决策 | 报告查看 |

### 5.3 关键人工确认节点

| 确认节点 | 触发条件 | 确认人 | 前端交互 |
|---------|---------|--------|---------|
| 工单下发 | 所有维修工单 | 维修班组长 | 工单卡片 + 确认/驳回 |
| 停线审批 | severity≥4 或影响总装线 | 生产主管 + 设备经理（双签） | 审批弹窗 |
| 紧急采购 | 金额 >¥50,000 | 采购经理 | 采购申请单 |
| 排产确认 | 所有排产计划生效前 | 生产计划员 + 生产部长 | 甘特图对比 + 确认 |
| 排产变更 | 影响交期或产能利用率<70% | 生产计划员 + 生产部长 | 变更对比 |
| 跨月订单拆分 | 跨月订单自动拆分时 | 生产计划员 | 拆分方案确认 |
| 供应商切换 | 任何供应商替换建议 | 供应链总监 | 分析报告 |
| 成本补录确认 | 月末成本补录数据提交 | 财务人员 | 补录表单 |
| **移动端意向订单转正式** | **现场接单确认后** | **业务人员 + 计划员** | **移动端确认 + PC端排产** |

## 七、数据方案（MySQL统一存储 · v6版）

### 7.1 数据库设计原则

| 原则 | 说明 |
|------|------|
| 统一MySQL | 所有业务数据、排产数据、成本数据、时序数据均存MySQL 8.0 |
| 分区表 | 时序数据（传感器）按月分区，避免单表过大 |
| FULLTEXT索引 | 知识库检索使用MySQL FULLTEXT替代向量数据库 |
| CTE递归查询 | 故障路径追溯使用MySQL 8.0 CTE替代图数据库 |

## 八、安全合规与边界设计

### 8.1 强制安全声明

每条 Agent 输出末尾自动附加：

> ⚠️ **安全提示：** 以上内容由 AI Agent 辅助生成，仅供辅助参考。涉及设备操作、焊接参数调整、产线停机、安全联锁等决策，必须由具备资质的专业人员现场确认后执行，不得直接作为操作依据。本系统不替代企业安全规范和人工判断。

### 8.2 移动端安全约束

| 约束项 | 说明 |
|--------|------|
| 🔴 移动端不可直接生成正式排产 | 仅生成意向订单，正式排产需PC端计划员操作 |
| 🔴 移动端不可修改已确认排产 | 只能查看，变更需走PC端审批流程 |
| 🟡 意向订单需二次确认 | 业务人员确认 + 计划员审核 |
| 🟡 敏感数据脱敏 | 移动端不展示成本明细、供应商价格 |
| 🟢 排产日历可查看 | 移动端可查看排产情况（只读） |

### 8.3 排产安全约束

| 约束项 | 说明 |
|--------|------|
| 🔴 排产不可自动生效 | AI排产方案必须经人工确认后方可下发 |
| 🔴 交期变更需双签 | 影响客户交期的排产调整需计划员+部长双签 |
| 🟡 产能超限需审批 | 超出日产能标准的排产需说明原因并审批 |
| 🟡 跨月拆分需确认 | 跨月订单自动拆分后需人工确认 |
| 🟢 预排可自动填充 | 预排订单填充空位可自动执行，但需标记 |

### 8.4 财务数据安全

| 约束项 | 说明 |
|--------|------|
| 🔴 成本数据权限隔离 | 成本数据仅财务+授权管理层可见 |
| 🔴 分摊规则变更需双签 | 财务经理 + 生产部长 |
| 🟡 补录数据需审核 | 月末补录数据提交后需财务审核 |
| 🟢 工令成本查询 | 生产人员可查询本工令成本 |

### 8.5 操作审计

- 所有 Agent 决策记录完整 Trace
- 人工确认/驳回操作留痕
- 排产变更记录完整版本历史
- 移动端操作日志（谁、何时、输入了什么、AI返回了什么）
- 不可篡改日志（哈希链）
